## 🎯 Temas clave del curso
- **Crime & punishment** + proceso judicial + headline language + media.
- **Grammar:** passive, causative have, impersonal passive, reporting verbs, modal deduction (present/past), should/ought to have, would rather / prefer, used to / be used to / get used to, conditionals, wish, articles.
- **Writing:** for-and-against (~150 words) con estructuras obligatorias en **negrita**.
- **Speaking:** interacción > perfección (opinión → explicar → ejemplo → preguntar al compañero).
- **Reading:** The Way Up to Heaven · Lamb to the Slaughter · Dip in the Pool · Mrs Bixby and the Colonel's Coat · Taste.

## 🔁 Flujo de trabajo con el Gentleman (yo)
1. **Tomar lección:** "Tomame lección de `grammar/modal-deduction.md`".
2. **Writing:** escribís acá en `writings/`, yo corrijo como la profe y te explico el porqué.
3. **Speaking:** te doy una pregunta → te grabás → transcribís (Dictado de Mac) → me pasás el texto → corrijo fluidez, naturalidad y errores.
4. Lo nuevo de cada clase lo volcás en la carpeta que corresponda para no perderlo.
