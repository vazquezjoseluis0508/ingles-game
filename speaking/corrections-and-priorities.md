# Speaking — Errores recurrentes y prioridades

| Prioridad | Dificultad | Qué practicar |
|---|---|---|
| Alta | will / would | second conditional y respuestas imaginarias |
| Alta | bloquearse al improvisar | frases automáticas de opinión y tiempo |
| Alta | responder al compañero | acuerdo, desacuerdo y preguntas |
| Media | artículos a/an | a good point, a difficult question |
| Media | formas verbales | choose/choice, find/finding |
| Media | singular/plural | responsibility/responsibilities |
| Media | preposiciones | on my first day |
| Media | pronunciación | shade, earlier, embarrassed, fall asleep |
| Media | contar experiencias | for example, I remember, when I… |

> Las mayores dificultades no fueron solo gramaticales: también **encontrar rápido qué decir** y cómo continuar tras la respuesta del compañero.

## Consejos trabajados
1. No memorizar discursos completos; recordar estructuras pequeñas adaptables.
2. No hablar demasiado: 2–3 frases y pregunta.
3. Agregar experiencias personales (son modelos para adaptar, no hechos reales verificados).
4. Reaccionar antes de cambiar de tema (*That's true / I agree / I see your point, but…*).
5. Variar las preguntas (no repetir siempre *What about you?*).
6. Usar frases para ganar tiempo cuando te bloqueás.
7. Priorizar fluidez sobre perfección.
