# 🗣️ Speaking — Senior 5 (A2/B1)

Examen **interactivo**: profesora + 2 alumnos. La profe presenta un tema con subtópicos y pregunta cuál elegís y por qué. No es memorizar discursos: es demostrar que podés opinar, justificar, dar ejemplos, interactuar y reaccionar.

## Estructura de cada intervención (15–30 seg)
1. **Opinion** → *I think…*
2. **Reason** → *Because…*
3. **Example / experience** → *For example…*
4. **Interaction** → *What do you think?*

> *"I think starting a new job would be exciting but stressful because everything is new. For example, I would have to meet new people and learn new things. What about you?"*

### Reglas tuyas (acordadas)
- No interrumpir mientras hablás (nada de "mhm", "ajá", "okay").
- Si leés una lista larga, correcciones **al final**, no frase por frase.
- Las transcripciones confunden **will/would**: no asumir error de pronunciación por eso.
- Prioridad: **fluidez antes que perfección**, nivel A2/B1, vocabulario simple.

**Meta final:** elegir un subtópico, explicar opinión, dar un ejemplo personal y conversar con otro alumno, SIN leer respuestas preparadas.
