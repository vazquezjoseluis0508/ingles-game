# Speaking — Plantillas para improvisar

## Paper 1 — Getting Lost
```
If I got lost in __________, I would feel __________.
First, I would __________ because __________.
For example, __________.
What would you do?
```

## Paper 2 — Feelings and Situations
```
I would choose __________ because __________.
I think I would feel __________ because __________.
For example, __________.
Have you ever felt the same way?
```

## Paper 3 — Sleep Problems
```
I'd like to talk about __________.
I think __________ can affect your sleep because __________.
For example, __________.
What do you think about that?
```

## Responder a un compañero
```
That's a good point. I agree with you because __________.
On the other hand, __________. What about you?
```

## Mostrar desacuerdo
```
I see your point, but I think __________.
For example, __________. Do you agree?
```

## Ganar tiempo
```
Let me think for a second. That's a difficult question.
I'm not sure, but I think __________.
```

---

## Plan de continuidad (5 etapas)
1. **Automatizar frases** clave hasta que salgan solas.
2. **Improvisar respuestas cortas** (2–3 frases, sin leer).
3. **Agregar experiencias** personales (trabajo, viajes, sueño, cambios de vida).
4. **Interacción real** con profe + 2º alumno, incluyendo preguntas inesperadas.
5. **Simulacro completo** de cualquier subtópico, sin respuestas preparadas.
